# Felix shield

- 5x12+4 split ortholinear keyboard (5x6+2 per side), nice!nano v2 + 128x32 SSD1306 OLED.
- Matrix: col2row, 5 rows x 7 columns per half; the right half uses `col-offset = <7>`.
- `felix.keymap` in this directory is the shield's default keymap. The user keymap lives in `config/felix.keymap`.
- RGB underglow is not supported by this config.
